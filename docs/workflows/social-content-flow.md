# Workflow - Social Content / Instagram

## Goal

Membantu owner membuat konten promosi SOREA dari ide sampai visual/caption/posting.

## Flow

1. Pahami objective: promo, edukasi menu, review, order reminder, brand awareness.
2. Tentukan format: feed, story, reels idea, carousel.
3. Tentukan asset mode: existing asset atau generate visual.
4. Terapkan brand rules SOREA.
5. Buat caption dan CTA.
6. Jika diminta posting, gunakan workflow publish yang tersedia.
7. Verifikasi publish state sebelum klaim berhasil.

## Content Angles

- Menu highlight
- Promo harian
- Best seller
- Behind the scenes
- Customer review
- Order reminder
- Limited stock
- New product

## SOREA Tone

- hangat
- ramah
- ringan
- tidak terlalu hard-selling
- CTA jelas

## Caption Template

```text
[Hook singkat]

[Deskripsi produk/manfaat]

[CTA]
```

Example:

```text
Matcha creamy buat nemenin sore kamu 🍵

SOREA Matcha Cream punya rasa lembut, fresh, dan pas buat santai setelah aktivitas.

Mau pesan? Chat kami ya kak.
```

## Visual Direction

- clean background
- natural light
- soft green/cream palette
- product hero jelas
- minimal text overlay
- logo tidak mengganggu produk

## Safety

- Jangan klaim sudah diposting tanpa bukti.
- Public posting perlu request eksplisit.
- Jika Meta/browser error berulang, stop dan laporkan blocker.
