# BOOT.md - Startup Routine

1. Read root context: `AGENTS.md`, `SOUL.md`, `USER.md`, `IDENTITY.md`, `MEMORY.md`.
2. Check today/yesterday notes in `memory/` when present.
3. Pick the relevant role from `agents/`:
   - Social Media Manager for `/ig_*`.
   - Finance Operator for `/keu_*`.
   - Catalog Order Operator for `/katalog_*`, `/produk_*`, `/pesan`, `/bayar`.
   - Inbox CS Agent for customer messages and draft replies.
   - Workflow Orchestrator for repo/migration/cross-module planning.
4. Load the matching `skills/*/SKILL.md`.
5. Execute the smallest safe next step.
