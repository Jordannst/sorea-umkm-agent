# Evaluation Rules

Karena dosen paling melihat `skills/` dan `agents/`, pastikan dua folder itu paling kuat.

## Agents Must Show

- role
- owns
- inputs
- outputs
- workflow
- boundaries
- handoff

## Skills Must Show

- YAML frontmatter
- when to use / triggers
- source of truth
- workflow steps
- safety rules
- examples/templates

## Repo Must Show

- clear README
- demo script
- command map
- architecture explanation
- seed/sample data
- no secrets

## Presentation Angle

Tekankan bahwa ini OpenClaw-native agent workspace, bukan copy Claude repo atau generic Python agent framework.
